# Spoje.Net @ GitHub

Czech IT company focused on banking integrations, accounting automation, and business tooling.

## Banking Integrations

### Czech National Bank (ČNB)

| Project | Description |
|---------|-------------|
| [CNB-Cache](https://github.com/Spoje-NET/CNB-Cache) | Application for downloading the CNB exchange rate list |
| [CNB-Tools](https://github.com/Spoje-NET/CNB-Tools) | Tools for working with CNB exchange rate data |

### Česká spořitelna (CSAS)

| Project | Description |
|---------|-------------|
| [csas-authorize](https://github.com/Spoje-NET/csas-authorize) | CSAS access token endpoint app |
| [csas-pohoda](https://github.com/Spoje-NET/csas-pohoda) | Download CSAS bank statements and import them into Pohoda |
| [csas-sharepoint](https://github.com/Spoje-NET/csas-sharepoint) | Download CSAS bank statements and upload them to SharePoint |
| [php-csas-webapi](https://github.com/Spoje-NET/php-csas-webapi) | PHP API client for CSAS production accounts |
| [pohoda-csas](https://github.com/Spoje-NET/pohoda-csas) | Integration between Pohoda and the CSAS accounts API |
